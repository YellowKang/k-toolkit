# 日期、颜色、IP、普通文件与长对话

2026-10-24。按 [能力巡检](tool-capability-audit.md) 的优先级继续实现。现有工具入口和旧链接保留，Agent 共 88 个 action；本轮新增 4 个普通文件动作和 2 个大结果引用动作。

## 手动与 Agent 共用计算

| 能力 | 结果与交互 |
| --- | --- |
| 日期差 | 按公历日期计算，不受本地 DST 日长影响；返回有符号总天数、月末截断的完整月/年、日历分量和含首尾日期的工作日。2024-01-31 → 2024-02-29 为 29 天、1 个完整月。工作日仅排除周六/日。 |
| 时间戳 / 时区 | 严格校验日期、偏移与 IANA 时区；支持自动识别和显式 s/ms/us/ns。微秒/纳秒整数先用 BigInt 除法转换，统一保留到毫秒，避免大整数舍入跨毫秒。DST 缺失时间拒绝，重复时间默认报错，可选较早/较晚偏移。无偏移输入使用指定时区，默认浏览器本地时区。 |
| 颜色 / 对比度 / 调色板 | 共享短 HEX、带 alpha 的 HEX、RGB(A)、HSL(A)、HSV、CMYK 解析。负 hue 可环绕，非法范围不静默夹紧；RGBA 保留 alpha 数值，HEX 透明度按 8 位量化。HSV/CMYK 单独提供透明度。对比度使用未舍入比值判断阈值，要求不透明颜色；调色板与页面完全共用生成逻辑。 |
| IPv4 | 八位组和 CIDR 前缀完整匹配，拒绝指数、空段、尾缀和前导零；区分总地址与可用地址，正确处理 /0、/31、/32。/31、/32 不把末地址标为保留广播地址；其他地址分类不构成公网可路由保证。 |

共享模块为 `compute/date.js`、`color.js`、`ip.js`。页面读取输入和展示结果，action 负责 schema 与返回契约。页面操作等待异步初始化后再填值，读取当前计算结果；失败不再把旧文本当作本次成功输出。颜色动作隔离作用域，避免覆盖手动页面的同名转换函数。

`date_diff`、`timestamp_convert`、`timezone_convert`、`color_convert`、`ip_calc` 已加入本地工作流白名单。计时器、番茄钟等有状态工具继续保留自己的交互，不强行合并为无状态动作。当前不扩展 IPv6、法定节假日或任意自然语言日期解析。

## 普通文件链路

1. 在 Agent 的附件按钮或 Base64 / Hash 页面选择真实文件，暂存区给出稳定 `fileId`。可以复用已选文件或上一操作生成的结果。
2. `list_files` 查看当前引用；`read_file` 分段读取 UTF-8；`file_hash` 对真实字节计算 SHA-1/256/384/512；`file_convert` 支持 Base64 编解码、JSON 格式化和 CSV ↔ JSON。
3. 文件结果卡片可下载实际 Blob、带入 Base64 / Hash，或把 UTF-8 文本带入普通文本工具。已有输入沿用替换保护，不依赖模型重述内容或生成下载地址。

源文件与结果分别最多 20 个 / 100 MiB，单文件与单结果 32 MiB；结果池按最旧项淘汰。Base64 编码输入最多 24 MiB，输出含 Data URL 头仍需满足 32 MiB。文件仅在当前标签页内存中保存，清除或刷新后 ID 失效；取消、清除和源文件替换后的迟到结果不会发布。无效批次不会覆盖原暂存。

文件哈希与 Base64 使用真实 Worker，12 秒超时，取消会销毁 Worker。Base64 校验字母表、填充与填充位，支持 URL-safe 和 Data URL；不把文件还原为可执行 HTML 预览。手动编码预览最多 64,000 字符，复制/下载使用完整结果。Hash 顺序处理，最多 10 个文件，每个 32 MiB。

UTF-8 文本读取最多 2 MiB，拒绝非法编码和含 NUL 的二进制；每次 `read_file` 默认 4,000、最多 16,000 个 UTF-16 字符，返回下次偏移和是否截断。文本转换沿用共享 CSV / JSON 的字符与结构上限。文件字节不会自动上传；Agent 读取的片段、文件元数据和处理结果会进入所选模型上下文。普通文件和图片分别管理文件池，结果卡片统一交接；文件动作未加入纯计算工作流白名单。

## 长对话与大结果

- AI 对话和 Agent 共用 16k / 32k / 64k 上下文预算，默认 32k。估算包含系统提示、工具定义、固定备注和回复预留；中文、ASCII 和图片分别估算，不是模型 tokenizer，也不自动探测服务商容量。
- 每次仅裁剪发送视图：保留当前完整一轮，按完整旧轮移除，工具调用与结果不会拆开。固定备注最多 4,000 字符，每轮保留；界面显示发送轮数、估算量和省略轮数。当前轮或系统部分已超预算时明确提示调整，原历史保留。
- 超过 8,000 字符的工具输出保存在本地，给模型发送 `resultId`、长度与最多 1,600 字符预览。`read_result` 分段读取，`transform_result` 直接使用真实字段继续计算，无需模型重新输入全文。结果池最多 40 项、8 × 1,024 × 1,024 个 UTF-16 字符，单项 131,072 字符；引用过期明确报错。继续计算文本仍受 65,536 字符动作输入上限约束。
- AI 对话初次渲染最近 40 条消息，每次向前加载 40 条并保持滚动位置，完整导出使用内存历史。刷新可恢复历史最多 500 条且序列化不超过 1,500,000 字符；超出的较早消息在本次会话仍可查看/导出，并显示刷新后不会恢复的提示。继续兼容原数组存储格式，历史元数据和上下文偏好纳入原备份组。
- 模型达到输出上限时显示可操作提示，允许提高输出上限后重试。重试保留用户问题和已完成工具结果，仅继续失败的模型请求。
