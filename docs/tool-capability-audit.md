# 工具能力巡检与第二轮改进

2026-10-24。检查范围为目录里的 92 个工具及 AI 对话入口：查看实现入口、共享计算调用、Agent action/页面操作映射和已有回归。下面区分本轮实改与剩余工作；目录巡检不等于所有工具的每个算法都完成了全面验证。

## 本轮完成

| 能力 | 已复现问题 | 修改与交互 |
| --- | --- | --- |
| 计算器 | Agent 的 `2^3` 为 1；页面连续运算丢中间操作数 | 共用有界表达式解析器，无 `eval`；幂右结合、科学函数、DEG/RAD、百分比与取余。页面可编辑完整表达式、键盘计算、复制完整数值、复用历史。 |
| 单位 / 存储 | 两套单位表；小数被舍成 0，MB 与 MiB 混用 | 同一单位表和精度，覆盖长度、质量、温度、面积、体积、时间、存储、速度；SI MB=10⁶ B，IEC MiB=2²⁰ B；旧别名仍可使用。空输入不显示虚假 0。 |
| URL | Agent 丢掉重复键与特殊键；页面去掉首尾空白、重复解码百分号；大量参数撑大 DOM | 共用解析/构建/编解码，保留有序 `entries` 和多值 `params`。明确组件/URI/表单编码；解析结果可带入构建器，复制完整数据，保留片段；每页 50 项。带入 HTTP 请求草稿后由用户显式发送。 |
| JWT | 手动解析中文乱码，exp=0 被忽略，未验签却显示“有效” | 统一 UTF-8 解码、NumericDate 类型及 exp/nbf 边界；时间状态与“未验证签名”分别展示。JWT 不进入通用文本草稿。 |
| CSV | `a,a,a_2` 表头覆盖第二列；展开对象路径冲突覆盖值；大行数 spread 溢出 | 唯一表头保留全部列（示例得到 a/a_3/a_2），保留特殊键，路径冲突明确报错。默认保持字符串与前导零；可选推断。统一页面和 Agent 转换，生成时直接得出列数，不为统计重解析完整 CSV。 |
| JSON Schema | 仅检查 type/required/items；`minimum`、`false` 等规则误报通过；仅用数组首项推断 | Ajv Draft-07 与标准 formats；从全部样本合并类型、可选字段。真实 Worker 校验，错误给出路径/规则；未知规则、无效 schema、远程引用报错；2 秒超时、手动取消、修改/离页丢弃旧结果。双栏编辑、复制/下载、继续处理。 |
| YAML / TOML / XML | 尚未开放工作流；YAML 引用可爆炸展开；XML 混合内容排版改动空白 | 增加展开/节点/深度边界；XML 保留混合内容及 `xml:space`，特殊子节点名不碰对象原型。纯计算动作可串联。DTD/实体声明明确不支持。 |
| Agent 页面操作 | URL decode 没切换模式；Schema validate 实际生成；主输入 0 被跳过；读取输出拿到旧模式的值 | 页面 runner 与新实现对齐，支持显式 Schema、正确编码模式、科学表达式、单位类别/别名；新页面计算失败不再报告“执行成功”。新增当前输出接口，读取实际校验结果、当前编码模式的结果，并保留文本首尾空格。 |

第二轮结束时 Agent 共 82 个 action；新增 CSV 双向转换、Schema 推断/校验、URL 构建、单位目录共 6 个。第三轮新增普通文件与结果引用后共 88 个，详见 [第三轮实现与边界](tool-capabilities-round3.md)。工作流新增 `csv-json-schema`、`yaml-json` 两个模板，并开放已校准的格式转换、URL、数学和单位动作。结果继续使用已有卡片的步骤选择、完整复制/下载和带入工具。

Schema 使用本地固定版本 Ajv 8.20.0、ajv-formats 3.0.1，许可证与摘要随仓库保存；重建脚本为 `scripts/vendor-schema.cjs`。运行时不访问 CDN。实现依据：[Ajv 浏览器运行说明](https://ajv.js.org/guide/environments.html)、[校验选项](https://ajv.js.org/options.html)。

## 性能与边界

- URL：最多 200,000 字符 / 5,000 参数，解析和编辑均每页 50 项；编解码/构建输入合并 180 ms。完整复制和生成不受可见页限制。隔离浏览器中，5,000 参数解析并渲染首屏约 3–4 ms；这是该环境的测量，不是所有设备保证。
- 数学：最多 4,096 字符、1,024 token、64 层；只计算有限实数，`%` 表示百分比，`mod` 表示取余。
- CSV：输入 1,000,000 字符、20,000 行、1,000 列、200,000 单元格；输出最多 2,000,000 字符。格式化后的 JSON 输出同样有边界。
- Schema：推断最多 50,000 节点 / 64 层；校验数据 1,000,000 字符、Schema 200,000 字符，组合结构最多 60,000 节点 / 64 层。校验器仅在 Worker 需要时加载，超时销毁 Worker；最多返回 100 条错误，单条路径/详细参数最多 2,000 字符，明确标记截断。推断只概括样本，业务约束仍需补充。
- YAML/TOML/XML：输入最多 1,000,000 字符，节点/展开次数最多 50,000、深度 64；YAML 循环引用拒绝。Agent 参数/结果及工作流还有更小的既有预算，不能用手动页面上限推断模型可接受上限。

## 其余工具的取舍

| 工具族 | 本轮结论与后续优先级 |
| --- | --- |
| JSON/转义/正则/Diff/行处理/命名 | 保持上轮共享模块与性能边界，继续复用已有结果交接；不再新增重复入口。 |
| Base64/Hash/HMAC/AES/OTP/密码 | 第三轮已将普通文件 Base64 / Hash 与 Agent 接入 FileSession，使用可终止 Worker 和统一文件结果卡片；图片文件保留独立池并交接。保留摘要、认证和加密区别；密码生成策略仍待校准。 |
| 图片/QR/EXIF/SVG/Favicon/占位图 | 已有图片池覆盖转换、EXIF、QR；SVG 保持隔离预览。下一步把图标/占位图生成结果接到同一文件池；生成与识别维持两个方向。 |
| 日期/时间戳/时区/农历/年龄/倒计时 | 第三轮已统一日期差、时间戳与时区，覆盖日历月末、微/纳秒精度、DST 重复/缺失时间并开放工作流。农历/年龄继续保留各自语义；计时器、番茄钟不强行改成无状态动作。 |
| 进制/Semver/中文数字/比例/CSS 单位/贷款/税费 | BigInt 进制、版本比较、中文数字已有算法测试；适合再抽独立 action。财税场景须另行核对适用规则，本轮不改口径。 |
| 颜色/渐变/阴影/Flexbox/裁剪/调色板 | 第三轮已共享严格颜色解析、短 HEX、透明度、对比度与调色板，保留交互预览。Firefox 拖拽回归从裁剪边缘控制点的可见区域抓取。 |
| HTTP/cURL/状态码/DNS/IP/UA/测速 | 第三轮已统一 IPv4 / CIDR 严格校验与 /0、/31、/32。继续共享 HTTP 草稿，避免自动联网；网络查询保留外部服务/CORS 失败反馈，响应导出仍可加强。 |
| UUID/Mock/Nginx/Docker/Git/权限/终端色/Token 估算 | 生成类工具各有独立输出语义，适合共享基础编码与导出，不宜只为减少菜单而硬合并。Token 工具仍为估算，不能标成精确 tokenizer。 |
| 笔记/待办/模板/会议/打字/趣味工具 | 保留有状态交互、清理和已有性能回归；不为“Agent 覆盖率”添加无用动作。 |
| Agent/对话 | 第三轮已实现完整轮次上下文预算、固定备注、跨轮大结果引用、40 条分批渲染及有界持久保存；输出上限可恢复重试。自定义工作流保存仍待实现，不引入额外编排服务。 |

- `TEST_BUILD=1 npm run test:capabilities`；加 `TEST_BROWSER=firefox` 运行 Firefox。覆盖实际 Worker、输入修订、页面操作、复制下载、真实 URL 草稿交接、中文/英文及 375/768/1440 布局。
- `TEST_BUILD=1 npm run test:capabilities-next`：第三轮日期/颜色/IP、普通文件与长对话专项，同样支持 Firefox。
- `test:catalog`、`test:agent-shared`、`test:workflows`、`test:performance`、`test:xss`、`test:i18n` 检查原有功能。
- 真实模型过程另记于 [本地网关联调](agent-local-validation.md)，与不调用模型的自动回归分开记录。
