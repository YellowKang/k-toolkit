# 轻量工具箱与 Agent 架构

## 当前结构

站点保持原生 JavaScript 和静态部署。工具页面、Agent 会话与模型适配器分层，避免为本地计算引入常驻服务。

```text
工具目录 ToolCatalog → 分类 / 搜索 / 收藏 / 工作台
                         ↓
                   路由与按需加载
                         ↓
                 工具页面 / 本地计算

AI 界面 → AgentSession → 模型适配器 → 配置的模型接口
              ↓
      动作注册表与参数校验
              ↓
      顺序执行 / 页面操作 / 本地计算
```

`public/tool-catalog.js` 统一工具 ID、分类、工作台关系、处理方式和文件输入标识。首页与侧栏展示九组工作台；搜索、旧链接和收藏仍可到达所有子工具。图片压缩与 WebP 共用实现和队列；HTTP 与 cURL 共用 RequestSession；存储换算复用 byte-convert。普通文本工具通过 ToolWorkspace 显式传递输入或结果，替换已有输入前确认。

ToolWorkspace 仅缓存白名单内普通文本工具的 DOM 与表单值，最多 10 个、单份估算 2 MiB、合计估算 8 MiB；不写 URL 或持久存储。相同语言返回时保留输入、选项、结果与事件绑定；换语言重建界面并恢复表单，提示重新计算。AES、JWT、2FA、ENV 等不进入通用缓存。导航、分类跳转、搜索结果与语言切换均经过离页清理；粘贴不触发全局执行。快捷提交只使用显式 data-tool-submit 标记，尊重输入法和局部处理。

RequestSession 只在当前标签页内存共享方法、URL、请求头和原始请求体。cURL 导入仅解析支持的参数，保留引号内空格，拒绝文件读取等不支持的语义；生成代码按目标语言转义。HTTP 显式发送，30 秒超时，可手动取消，离页中止；响应通过页面与控制器身份检查后才显示。已有成功请求历史仍使用原浏览器存储机制。

番茄钟使用截止时间，秒表使用开始时间与累计耗时；切页停止页面刷新订阅，计时状态和活动条持续保留在内存，刷新清除。待办删除使用可撤销提示，恢复时读取最新列表，批量清理确认后执行。

Markdown 使用独立的内存草稿与 180 ms 合并更新；代码片段占位符用两次线性扫描恢复，预览仍经过 HTML 白名单过滤。超过 100,000 字符暂停自动预览，由用户手动更新；复制刷新到最新内容，离页清除定时器与媒体查询订阅。工具专用 CSS 随页面按需加载并纳入构建清单。全局装饰取消常驻脉冲、卡片图层提示和大面积模糊；切页只做透明度动画，不强制同步布局。时钟按分钟更新，后台和手机不写入隐藏时钟。

JSON 与字符串转义复用按需加载的 `compute/json-text.js`。JSON 字符串通过解析解开，不做全局反斜杠替换；显式递归展开只转换结构化对象/数组，结果使用无原型对象保留特殊键。输入上限 1,000,000 字符，展开上限 8 层编码、64 层结构和 20,000 节点，超限失败不输出部分结果。自动识别延迟 220 ms，超过 100,000 字符暂停。树形界面按 500 节点/20 层预算渲染，节点直接保存值与父引用，复制/编辑不依赖路径解析和可见文本；完整复制不受树显示上限影响。输入替换保留一次撤销，状态绑定当前草稿 DOM，离页取消排队任务。手机工作台标签横向滚动，当前标签进入可视范围；复制成功在原按钮反馈，避免连续复制堆叠提示。

SQL 将字符串、引用标识符、注释与 PostgreSQL dollar quote 作为不透明词元，排版只调整外部空白和关键词，压缩保留行注释后的换行；方言选择控制引用与注释规则，不能替代数据库语法解析。文本对比先裁去公共前后缀，再求最短编辑路径；计算最多 200,000 个 token、约 4 MiB 对角线轨迹和 2,000,000 次搜索步骤，超限明确报错。DOM 每页最多 200 段，完整差异保存在当前工具节点，复制/下载不依赖可见页的 innerText。

正则使用可丢弃 Worker，输入更改、离页或语言切换终止旧任务；启动后 1.5 秒仍未完成则终止，结果仅在 Worker 身份和页面存活检查后显示。限制文本 200,000 字符、表达式 5,000 字符、替换模板 10,000 字符、匹配 2,000 处和输出 2,000,000 字符。捕获详情仅展示前 20 个匹配、每个最多 32 组/每组 2,000 字符，并明确标示展示上限；替换超限不输出部分内容。Worker 不可用时提示重试，不回退到主线程执行不可信表达式。

共享能力通过 `compute/` 按需加载，覆盖文本、格式、图片、数学/单位、URL/JWT，以及日期、颜色、IPv4 和普通文件。页面负责输入、状态和展示，Agent action 负责 schema 与结果契约。JSON Diff 的路径是 JSON Pointer（根为空字符串），检查自有键；合计最多 40,000 节点、64 层、5,000 处差异和 2,000,000 字符输出。SQL 与文本 Diff 单份输入上限 1,000,000 字符。正则客户端统一负责超时、AbortSignal 与 Worker 释放。

ImageSession 给用户选择的 File 和生成的结果分配稳定 ID，向模型仅提供文件信息与处理结果。源文件和结果池各上限 20 张 / 100 MiB；结果池按最旧项淘汰，清除增加世代标记并让旧 ID 失效。共享图片模块负责有界解码、Canvas 导出、EXIF 解析和本地 jsQR。页面与 Agent 都检查取消状态，发布 Agent 输出前检查世代；同一次批处理持有输入快照。清理共享文件引用不会抹掉图片页面已经展示的独立结果。临时解码 URL 在 finally 中释放，下载 URL 延后释放，页面预览 URL 在替换/离页时释放。

AgentResults 直接绑定执行器结果；最终值与 returnSteps 中间值可选、复制、下载或通过 ToolWorkspace 传递。预览与详情分别限制 2,000 / 12,000 字符，完整下载使用 Blob；文件卡片直接暴露下载与后续图片工具，不用模型生成下载链接。可编辑动作只允许已校准的本地计算与图片动作，经过原有 schema/取消/超时执行器；包含密钥字段的参数不进入编辑器。快捷助手保留真实 DOM 节点，重开不会丢失结果控件的监听器。

FileSession 管理普通文件的真实 File / Blob 与稳定 ID，输入和结果各最多 20 个 / 100 MiB、单项 32 MiB，刷新/清除失效。Agent 附件、Base64 与 Hash 共用选择/暂存，结果卡片按文件种类下载或交接。`compute/file.js` 在 Worker 中处理摘要与 Base64，12 秒超时和取消均终止 Worker；文本转换复用 JSON / CSV 共享能力。UTF-8 读取限 2 MiB，按字符切片供模型按需读取；不会自动上传文件字节。图片仍使用 ImageSession，卡片层兼容两个文件池。

AgentContext 在请求前构建完整轮次的发送视图：包含系统、工具定义、固定备注与回复预留，默认 32k 估算预算，可选 16k / 64k，保留当前完整轮次并从旧轮开始裁剪。原历史不修改；当前轮超过预算会报错。AgentResultStore 把超过 8,000 字符的工具结果替换为 resultId 与预览，最多保留 40 项 / 8 × 1,024 × 1,024 字符，read_result / transform_result 使用真实本地数据继续处理。预算是估算，不能替代服务商 tokenizer。网络失败和输出达到上限均支持保留已完成工具的重试。

加载器按脚本路径保存 Promise，合并预加载与导航同时发生的加载请求。加载失败可重试，已加载脚本不会在当前页面会话中重新执行。工具打开时才注册清理钩子，预加载不能覆盖当前页面的清理逻辑；离开工具时调用钩子释放页面资源。长期演进可迁移为 ES modules，但不能通过删除 script 标签来模拟 JavaScript 内存卸载。

AgentSession 每次请求建立独立运行上下文与 AbortController，防止已取消任务的迟到结果写入新任务。模型返回的动作按顺序执行；入参先通过内置工具所用的 schema 子集校验，执行有超时与迭代上限。动作可通过第二个参数的 `signal` 配合中止。取消时清理不完整的 assistant/tool 历史配对，但不撤销已经发生的副作用。

Agent 的共享设置入口由 `agent-ui-part3.js` 提供，`AG.profile(adapter)` 将非敏感设置放入 `ag_profiles`，密钥仍单独存入 `ag_key_*`，普通备份不会携带密钥。旧全局设置只归属原选中服务商；保存先暂存旧值，失败时回滚并提示。设置事件不携带密钥，配置变化保留 Agent 历史，下一次请求读取新配置。Agent 加载器复用每个脚本的 Promise，避免聊天与浮窗并发初始化重复执行。

`AgentTransport` 统一端点解析、错误分类、可取消等待和超时；地址支持 origin、版本路径和完整端点，拒绝混入凭据或查询参数，不自动重写协议。错误不显示上游正文。SSE 支持跨块 UTF-8、CRLF、多行 data 和 1 MiB 事件上限，取消/提前退出会取消 reader。Agent 模型请求 60 秒超时并中止真实请求；网络重试保留已完成工具消息、累计工具预算和用户问题，不自动重做工具。

设置页可显式获取 `/models`（15 秒超时、1 MiB 响应和 500 项上限），仍支持手填；修改连接或切换协议会取消未完成获取，迟到结果不会覆盖新配置。模型列表不是可用性保证，需再测试连接。上游错误正文最多读取 16 KiB，只把已知的模型路由失败映射成固定提示，不回显模型名、私有地址或密钥。

Responses 适配器按实际 Content-Type 处理 JSON 或 SSE，包括网关对非流式请求返回 SSE 的情况。工具调用与结果使用顶层 `function_call` / `function_call_output`，以 `call_id` 配对；使用 `store:false` 和完整历史，不同时传 `previous_response_id`。同一端点和模型会重放原始 output items（含推理项），跨模型切换使用通用文本/工具历史。工具定义显式 `strict:false`，避免把可选参数隐式变为必填。缺少终止事件会报告传输中断。

协议依据：[Responses 消息迁移](https://developers.openai.com/api/docs/guides/migrate-to-responses#2-map-messages-to-items)、[函数调用结果处理](https://developers.openai.com/api/docs/guides/function-calling#handling-function-calls)。

AI 对话每轮绑定独立运行标识，迟到结果不能改写新对话；发送前保存用户消息，停止/错误保留部分正文。重生成只操作最后回复，失败和取消时保留原回复；清空可即时撤销。流式输出每 100 ms 合并渲染，超过 100,000 字符按纯文本展示，总输出上限 1,000,000 字符，60 秒无响应中止。用户向上滚动后暂停自动跟随；输入与待发送图片只在当前页面会话内保留，离页中止请求。历史初始渲染最近 40 条，每次向前加载 40 条；持久保存兼容原数组格式，最多最近 500 条且序列化不超过 1,500,000 字符，未保存部分明确提示。内存历史和完整导出保留本次会话全部内容；图片最多 4 张、每张 2 MiB。连接测试只验证基础对话，不代表工具调用或图片能力已经通过真实服务验证。

哈希/HMAC 使用输入修订号丢弃过期结果；清空与离页使旧任务失效，校验始终读取当前有效来源。文件按顺序计算，最多 10 个、单个 32 MiB；文件摘要使用可终止 Worker，停止会销毁当前 Worker 并保留已完成文件。文本 WebCrypto 仍通过修订号隔离迟到结果。输出独立于文件选择区，支持复制和文件来源比对。

SVG 预览以图片方式展示，避免将用户提供的 SVG 直接插入页面 DOM。图片压缩与 WebP 共用有界会话；Base64 通过 FileSession 管理普通文件，继续兼容从 ImageSession 交接的图片。

数学、单位、URL、JWT、CSV 和 Schema 由同一组 `compute/` 模块供页面与 Agent 调用。Schema 使用本地固定版本 Ajv/ajv-formats，在可销毁 Worker 中运行；2 秒超时、输入修改、取消及离页均不会将旧结果写入当前页。推断检查所有样本的类型与可选字段，校验未知关键字或缺失引用会失败，不发送远程 Schema 请求。URL 参数解析/编辑每页 50 项，复制保留完整数据；URL 带入 RequestSession 只更新草稿。模块上限和新工作流契约见 [能力巡检](tool-capability-audit.md)。

## 本地工作流

`ToolCompute` 为 Base64、命名风格和行清洗提供页面/Agent 共享函数；`compute/` 下的模块（Cron、CSV、农历、格式转换、.env、AES）由页面与 Agent 按需加载同一份代码。AES 基于 WebCrypto，Chrome 拒绝的 192 位密钥改用模块内纯 JS 实现，格式与互通约定见 [AES 说明](aes.md)。`AgentWorkflow` 允许已校准的本地动作按序组合，通过 `$ref` 传递有类型的步骤结果，不再由模型重新输入中间数据。计划在执行前检查动作白名单、重复 ID、引用方向和参数结构；执行时校验引用解析后的参数，失败/取消即停止。UI 复用结果卡片与进度事件，本地斜杠命令也通过 AgentSession 的同一执行边界。具体接口、限额和模板见[工作流文档](agent-workflows.md)。

图片压缩与转换已共享文件工作台；哈希与 HMAC 保留不同操作语义，二维码生成与识别保留方向。HTTP 请求测试与代码生成共享请求配置，状态码查询仍是独立参考功能。数据格式转换可继续统一解析入口；JSON 对比与文本对比保留各自比较逻辑。

GitHub Pages 继续承载静态前端；只有需要隐藏密钥、统一鉴权或跨域代理时才增加独立后端。当前不需要为了这些改进引入多 Agent 服务、数据库或完整任务编排平台。

## 验证边界

单元测试覆盖 Agent 取消、旧响应隔离、顺序依赖、参数校验、超时和迭代限制；AES 用 NIST SP 800-38A 与 GCM 规范向量、OpenSSL 命令行密文和 Node（OpenSSL）参考实现双向校验。浏览器回归覆盖图片流程、分类/工作台、旧入口/收藏、脚本重复加载、SVG 隔离和 AES 页面互通。浏览器测试屏蔽外部 HTTPS 请求，不代表真实模型或第三方服务已完成联调，也未覆盖全部工具的算法正确性。

## 依赖维护

开发服务使用 Node.js 自带 `--watch`，移除 nodemon 及其监听依赖。`qs` 使用 override 升级到已修复版本，因为 Express 4 的依赖范围仍限制在旧的小版本；升级 Express 后应重新检查是否还需要该 override。依赖更新后运行 `npm audit` 和浏览器回归，审计结果只反映当时已公布的通告。

## 发布和客户端更新

构建为 HTML 注入内容版本，所有应用脚本/样式 URL 携带版本参数，生成 `version.json` 及 Worker 内的 SHA-256 资源清单。Worker 安装新版本时，先按路径在本 scope 保留的旧版本缓存中由新到旧查找，重新计算 SHA-256 与新清单一致才复制，否则带新版本参数从网络下载并校验；路径只用于定位候选，内容损坏或被篡改的副本不会进入新版本。最多并发处理八个资源，全部校验通过后才完成安装；任一文件失败即删除新缓存、停止其余处理并保留当前版本。用户确认更新后发送 ACTIVATE，只有发起操作的标签页刷新；旧标签页按旧版本参数读取保留缓存，超出最近三个版本的资源返回失败，避免混用新脚本。

缓存前缀包含 scope 路径，不清理同域其他项目。version.json 不经过 Worker 缓存，检查使用 no-store 与查询参数；Worker 注册使用 updateViaCache:none。GitHub/CDN 仍可能有传播延迟，更新失败保留现有运行版本。GitHub 工作流使用 configure-pages/upload-pages-artifact/deploy-pages，仓库 Source 需设为 GitHub Actions。

ImageSession 只保留最近一组 File 引用，最多 20 个、共 100 MiB，提供清除和结果暂存；显式“转为 Base64”会带入选定结果。元数据接口仅返回名称/类型/大小，不把文件内容发送给模型。压缩/转换会话同样限制 20 个输入、共 100 MiB，单张 4000 万像素，输出合计 100 MiB，顺序复用 Canvas。离页取消未完成计算并移除订阅，保留已完成的结果 URL；替换图片、重新处理或清空时释放 URL，刷新后整个会话消失。
